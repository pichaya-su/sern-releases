SERN

A simple, fast Git GUI for Windows.

Stage single lines, rebase by dragging a branch, review pull requests. SERN runs your own git underneath, so everything it does is plain Git.

Download for Windows Read the guide

For Windows 10 and 11, with Git for Windows installed. Installs without an admin prompt and updates itself.

What you can do in SERN

Everything here is in the current release. The guide walks through each one.

  1. Changes and commits

    See exactly what goes into a commit, and take back what you didn't mean to do.

    • Stage files, hunks or single lines. Click line numbers to pick lines, Shift+click for a range, and discard the same way.
    • Undo, instead of "Are you sure?" Discarding changes, deleting a branch or a stash, and a hard reset happen at once and offer Undo.
    • Commit, amend, push. The commit button also commits and pushes, or commits and syncs (pull, then push).
    • Diffs you can read. Syntax highlighting, unified or side by side, and before and after previews for images.
    • Always current. Edits and commits made in your editor or terminal show up right away.
    Space
    Stage or unstage
    CtrlEnter
    Commit
    CtrlShiftEnter
    Commit and push
    CtrlShiftD
    Unified or side by side

  2. History you can rearrange

    One graph across every branch, and the tools to reshape it by hand.

    • Commit graph. Open a commit to read its message, files and diffs. Right-click one to copy its hash, cherry-pick, revert, reword or reset.
    • Drag branches. Drop a branch on another to fast-forward, merge or rebase, on a remote branch to push, or on a commit to reset or branch from it.
    • Interactive rebase. Reorder, reword, edit, squash, fixup or drop commits with a drag or the keys P, R, E, S, F and D. A finished rebase offers Undo.
    • File history and blame. List the commits that changed a file, following renames, and see who last changed each line.
    Ctrl2
    History
    CtrlF
    Search commits
    Esc

  3. Branches, merges and stashes

    Switch, merge and set work aside without remembering a single flag.

    • Branches. Double-click to switch, and create, rename or delete them. A switch that would conflict offers to stash your changes first.
    • Merge your way. Fast-forward when possible, always make a merge commit, or squash. Conflicts wait for you to resolve them, then continue or abort.
    • Stashes. Stash everything or only the files you pick, untracked ones too, and browse a stash's diffs before restoring it.
    • Tags. Tag any commit, with a message for an annotated tag, and push one or all of them.
    CtrlB
    Switch branch
    CtrlShiftN
    New branch

  4. Sync and pull requests

    Fetch, pull and push with live progress, and review pull requests next to your code.

    • Sign-in handled. SERN signs in through Git Credential Manager, so pushing over https needs no setup.
    • Pull and push, your way. Merge or rebase on pull, per repository. Push to any remote and branch, send tags along, or force push with lease after seeing which commits it would replace.
    • Pull requests on GitHub and Bitbucket Cloud. See open ones with their checks and reviews, browse their commits and files, check one out (from a fork too) or merge it.
    • Create pull requests. The title and description come from the branch's commits, and the branch is published first if it isn't on the remote yet.
    CtrlShiftF
    Fetch
    CtrlShiftP
    Pull
    CtrlP
    Push

  5. Made for the keyboard

    Every action in a menu is also a command you can type.

    • Command palette. Run any action by name, or find a file to see its history.
    • Tabs. Open several repositories at once. Each tab keeps its own view and draft commit message, and a push keeps going when you switch away.
    • Git console. Type any git command in a drawer under the main view, with live output and completion for commands, options, branches and files. Commands that lose work ask first.
    CtrlK
    Command palette
    Ctrl`
    Git console
    CtrlT
    New tab
    CtrlTab

  6. Make it yours

    Add the commands your team keeps typing, and pick how SERN looks.

    • Custom actions. Add commands such as git tag {input:Tag name} {commit} or code {repo} to the palette and right-click menus.
    • Plugins. Install a .sernx plugin to add commands that can call web APIs like Jira or GitHub. Each runs in a sandbox with only the permissions you allow. Write your own.
    • Themes. Light and Dark, Glass, Telemetry and Orbit, each in a light and a dark version. Try them on the picture at the top of the page.

  7. AI, when you want it

    Off until you connect Anthropic (Claude) or any OpenAI-compatible server, such as OpenAI, Ollama, LM Studio or OpenRouter. Your key stays in Windows Credential Manager.

    • Commit messages. Written from your staged changes, in the style of your recent commits, Conventional Commits, or plain.
    • Ask AI. A chat that knows your branch, changes and recent commits. The git commands it suggests run in the console, so risky ones still ask first.
    • Explain. Have a commit explained, or a failed command and how to fix it.
    • Conflicts. Get a proposed merged file to review before it replaces yours.

    Write the commit message
    CtrlShiftA

Plugins add your own commands

A plugin is a folder with a manifest and one JavaScript file. It adds commands to the palette and right-click menus, runs in a sandbox, and gets only the permissions and web hosts you allow when you install it.

  • Writing pluginsInstalling, sharing, the manifest, the API and the sandbox.
  • API guide for AI agentsGive it to an AI agent to have it write a plugin for you.
  • TypeScript typessern.d.ts, for completion and checks in your editor.
  • ExamplesCommit link, Jira issues and Run script, with their code.
sern-plugin.json
{
  "id": "sern.commit-link",
  "name": "Commit link",
  "version": "1.0.0",
  "sernApi": 1,
  "main": "main.js",
  "permissions": ["repo", "clipboard"],
  "contributes": {
    "commands": [
      { "id": "copy-commit", "title": "Copy commit link", "scope": "commit" }
    ]
  }
}
main.js
sern.commands.register("copy-commit", async (ctx) => {
  // "git@github.com:me/app.git" → "https://github.com/me/app"
  const base = webUrl(await sern.repo.remoteUrl("origin"));
  await sern.clipboard.writeText(`${base}/commit/${ctx.commit.id}`);
  await sern.ui.toast("Link copied", "success");
});

Shortened from the Commit link example, which also defines webUrl. It adds "Copy commit link" to the right-click menu of every commit in History.
